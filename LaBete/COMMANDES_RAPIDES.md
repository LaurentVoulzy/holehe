## 🎯 COMMANDES GLOBALES

### Contrôle Général
```
/start        → Menu principal
/status       → Statut de tous les bots
/all_on       → Activer TOUS les bots
/all_off      → Désactiver TOUS les bots
/forex_on     → Activer tous FOREX
/forex_off    → Désactiver tous FOREX
/crypto_on    → Activer tous CRYPTO
/crypto_off   → Désactiver tous CRYPTO
```

### Statistiques
```
/stats        → Stats globales
/pnl          → P&L global
/winrate      → Win rate global
/trades       → Résumé des trades
/daily        → Rapport quotidien
/weekly       → Rapport hebdomadaire
```

### Positions
```
/positions    → Toutes les positions
/close_all    → Fermer TOUTES les positions ⚠️
/tp1_all      → Forcer TP1 sur toutes
/be_all       → Break Even sur toutes
```

### Alertes & Monitoring
```
/alerts       → Configurer alertes
/news         → News économiques
/calendar     → Calendrier du jour
/risk         → Statut risque
/drawdown     → Drawdown actuel
```

### Notifications
```
/notify_on    → Activer notifications
/notify_off   → Désactiver notifications
/notify_trades → Notifs trades uniquement
/notify_all   → Notifs complètes
```
